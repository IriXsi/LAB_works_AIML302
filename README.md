# AIML302: Deep Learning and Neural Networks — Lab Practicum

Practical implementations, mathematical derivations, and deep learning architectures developed for the **AIML302 (Deep Learning and Neural Networks)** course at Amity University in Tashkent.

This repository covers the complete progression from foundational mathematical models (built from scratch in NumPy) to modern computer vision, representation learning, and sequential time-series architectures in PyTorch.
